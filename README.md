## 🎩 Introduction

**ChitChat** is a robust, full-stack real-time communication platform. Built using the modern MERN stack, it offers an intuitive and seamless experience for instant text messaging, peer-to-peer video/audio calls, and media sharing. The UI is heavily optimized for all devices, bringing fluid animations and a premium feel to everyday conversations.

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **⚡ Real-Time Chat** | Instant text communication with live "typing..." indicators. |
| **📞 WebRTC Calls** | High-quality, peer-to-peer audio and video calling. |
| **🔐 Secure Auth** | Robust user login/logout powered by JWT and bcrypt. |
| **📁 Media Sharing** | Send and receive images or files seamlessly via Cloudinary. |
| **😊 Expressive** | Integrated emoji picker for expressive messaging. |
| **🔔 Notifications** | Real-time push alerts so you never miss a message or call. |
| **📱 Responsive UI** | Fully optimized for Mobile, Tablet, and Desktop screens. |

## 🛠️ The Tech Stack

- **Frontend:** `React.js`, `Tailwind CSS`, `Framer Motion` (Animations), `Lucide React` (Icons)
- **Backend:** `Node.js`, `Express.js`
- **Real-Time Engine:** `Socket.io`
- **Audio/Video:** `WebRTC`
- **Database:** `MongoDB`
- **Media Storage:** `Cloudinary`
